## IPv6-only или обычный VPS: где экономия оборачивается проблемой

IPv6-only берите в трёх случаях: проект уже работает на IPv6 и вам нужен дешёвый узел; это тестовая машина, зеркало, внутренний сервис или сборка, куда не нужны входящие соединения по IPv4; вы готовы отдельно настроить доступ к внешним сервисам, которые по умолчанию ходят по IPv4.

Не берите, если ставите обычный сайт с посетителями, панель управления, к которой подключаетесь из домашней сети, или магазин с платёжными модулями. IPv4 до сих пор нужен большинству внешних интеграций: почтовым шлюзам, платёжным колбэкам, сторонним API. Разница в 91 ₽/мес на «Сириусе» не покрывает вечер, потраченный на обходные схемы.

Проверять нужно именно конфигурацию в корзине: «Сириус» и «Сириус IPv6» стоят в одной таблице и отличаются одной строкой в названии.

## «Порт 300 Мбит/с (fair-share)»: что это значит на практике

Порт в таблице не выделенная полоса. Провайдер сам помечает его как fair-share и приводит ориентир по объёму: 300 Мбит/с соответствуют 93+ ТБ в месяц, 400 Мбит/с — 124+ ТБ, 500 Мбит/с — 155+ ТБ, 750 Мбит/с — 232+ ТБ, 1000 Мбит/с — 309+ ТБ.

Практический вывод: для сайта, который отдаёт десятки гигабайт в месяц,任何 из этих значений с запасом хватает, и разница между 300 и 750 Мбит/с не ощущается. Она важна для раздачи файлов, стриминга, бэкапов и зеркал, где счёт идёт на терабайты. Гарантировать постоянные 300 Мбит/с в пиковый час никто не обещает: скорость делится между пользователями узла.
